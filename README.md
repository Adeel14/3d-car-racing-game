# 3D Car Racing Game

A browser-based 3D racing game built with HTML, CSS, and Three.js.

## Features
- 3D road and car scene
- Keyboard steering controls
- Moving traffic cars
- Coin collection system
- Score, speed, health, and distance HUD
- Easy / Normal / Hard difficulty modes
- Pause menu and restart flow
- Best score saved in browser local storage

## Run locally
Open a terminal in the project folder and run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls
- A / D or Left / Right arrow keys: steer
- P: pause / resume
- R: restart after crash
- M: return to main menu

## Files
- `index.html` — main UI and HUD
- `style.css` — styling and menu layout
- `script.js` — game logic and 3D scene
